# vaculik.info

Rodinný informačný systém – kalendár, škola, platby, dokumenty, zdravie, domácnosť a asistent na jednom mieste.

- Stack: PHP 8.2+ · CodeIgniter 4 · MySQL 8 · HTMX + Alpine.js + Tailwind · PWA
- Hosting: Websupport

Návrh logickej štruktúry, modulov, dátového modelu a fáz realizácie: [docs/ARCHITEKTURA.md](docs/ARCHITEKTURA.md)
